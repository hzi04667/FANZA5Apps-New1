# FANZA → X 5分割アプリ

Pixel 8向けに、処理を5本へ分割したAndroidアプリです。

## 使う順番

1. **01 FANZA作品検索**: DMM WebサービスのAPI ID、アフィリエイトID、検索語を入力し作品を選ぶ。作品情報一式がクリップボードへ入ります。
2. **04 画像準備**: 「クリップボード読込」→公式サンプル画像をダウンロード。
3. **02 リンク準備**: 「クリップボード読込」→アフィリエイトURLを確認（作品情報は維持）。
4. **03 X投稿文**: 「クリップボード読込」→投稿文を作成・コピー。
5. **05 X投稿・履歴**: 「文を貼付」→「画像を選ぶ」→「X投稿画面を開く」。X側で最終確認して投稿すると、アプリ内へ履歴が残ります。

## APKの作り方（GitHub）

このフォルダの中身をGitHubリポジトリへアップロードし、**Actions → Build five APKs → Run workflow**。完了後、Artifactsの **FANZA-5-APKs** をダウンロードします。

## 必要なもの

- DMM WebサービスのAPI ID
- DMMアフィリエイトID（サイト審査承認後）
- Android版Xアプリ

## 安全上の設計

- X APIキーは不要・保存しません。
- 投稿は勝手に確定せず、X公式画面で本人が最終確認します。
- 公式APIが返すアフィリエイトURLとサンプル画像URLだけを扱います。
- `#PR` を初期文面に含めています。
